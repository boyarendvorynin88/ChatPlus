# ChatPlus — Веб-Мессенджер

Интерфейс локального мессенджера с поддержкой синхронизации между вкладками в реальном времени, разработанный в рамках курсового проекта.

##  Функционал:
* **Авторизация и сессии:** Регистрация и вход пользователей, сохранение активной сессии после перезагрузки страницы (`LocalStorage`).
* **Живой чат:** Моментальное получение сообщений в соседних вкладках браузера без перезагрузки (через событие `storage`).
* **Профиль:** Редактирование никнейма, смена аватара по URL-ссылке и статуса.
* **Черный список:** Возможность блокировать пользователей с последующей разблокировкой во вкладке «Блок».
* **Групповые чаты:** Создание общих комнат, где сообщения видны всем участникам с отображением их ников.
* **Дополнительно:** Панель эмодзи и отправка файлов.

## Были использованы:
* **HTML**,
* **CSS**,
* **JavaScript**.

## Как запустить проект локально:
1. Скачайте файлы `index.html`, `style.css` и `main.js` в одну папку.
2. В Visual Studio Code должно быть установленно расширение "Live Server". В `index.html` слево внизу нажмите Go Live.
3. Дублируйте открывшуюся вкладку чтобы начать чат.
